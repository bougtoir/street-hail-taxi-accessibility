# CEUS SUBMISSION AUDIT

Checked the current ScienceDirect journal page for Computers, Environment
and Urban Systems (0198-9715, Elsevier; EiC Tony Grubesic; APC USD 4,280 OA
option; subscription route free). The standalone Guide-for-Authors page did
not render programmatically; requirements below reflect the standard current
Elsevier/CEUS requirements — verify on Editorial Manager at submission.

- Article type: full-length Article (Your Paper Your Way formatting
  flexibility applies at initial submission).
- Abstract: ~250 words. Ours: ~260 — trim a sentence if the editor enforces
  strictly.
- Keywords: 6 provided.
- Highlights: required by Elsevier — CEUS_HIGHLIGHTS.docx (5 bullets, <=85
  chars each).
- Title page info: author name/affiliation to be filled by the author.
- Declarations included in manuscript: competing interests, funding, data
  availability, author contributions.
- Figures/tables embedded near first citation for review (inline docx);
  separate figure files (PDF/PNG) also provided for production.
- Data availability statement included; code + derived tables in repo.
- Cover letter: CEUS_COVER_LETTER.docx, tailored to journal fit.
- No Paper 2 content (field observation, waiting time) included.

Deviation note: abstract slightly exceeds the strict 250-word guide value
found via third-party requirement trackers; flagged for author trim at
submission.
