Anonymous reproducibility materials for peer review

These materials accompany a manuscript under double-anonymized peer review. They contain the analysis code, derived data, machine-readable result tables, figures and the canonical numerical registry behind every number reported in the manuscript.

Study: internal stress tests for constructed spatial opportunity surfaces (a street-hail relocation demonstration in five central Tokyo wards). Fixed random seed 42.

Contents

Path What it is
analysis/*.py analysis pipeline (acquisition, segment construction, relocation optimization, statistics, ablation, transfer, permutation nulls, figures, registry)
analysis/canonical_results.json canonical numerical registry; every number in the manuscript is read from this file
tables/ machine-readable result tables (CSV/JSON)
figures/ manuscript figures (PDF/PNG)
data/processed/ derived arrays (ablation, transfer, permutation-null results) and the pipeline log the registry reads
cache/ archived OpenStreetMap/Overpass responses (OSMnx cache)
DATA_SOURCE_AUDIT.md input data sources, versions and network descriptors
MANIFEST.csv path, size and SHA-256 of every file
LICENSE licences (code MIT; derived tables and figures CC BY 4.0; third-party inputs keep their own terms)

Install

Python 3.10.

pip install -r requirements.txt

Quick check (about a minute): regenerate the reported numbers and verify integrity

python tests/verify_reproduction.py

The check does two things:

  1. It verifies every file against MANIFEST.csv.
  2. It runs analysis/build_canonical_results.py, which reads tables/, data/processed/ and DATA_SOURCE_AUDIT.md and rewrites analysis/canonical_results.json. It then confirms that the regenerated registry is byte-identical to the archived one (SHA-256 ee1ce5bb26df5605aec7b803c459056b525de133b7f1d9bf8e81d448e33a22ac).

Full pipeline (hours; not needed for the quick check)

  1. python analysis/download_data.py all: OSM drive/walk networks and POIs via Overpass, plus MLIT N02 stations. OSMnx uses the archived responses in cache/.
  2. python analysis/build_segments.py (SIGMA env: 300 default; 150/500 sensitivity)
  3. python analysis/run_relocation.py
  4. python analysis/analyze_stats.py
  5. python analysis/run_ablation.py
  6. python analysis/run_ceus_analyses.py: clustered inference, cross-specification transfer, permutation nulls (the script name is historical)
  7. python analysis/make_figures.py, analysis/make_ceus_figures.py, analysis/make_framework_figure.py
  8. python analysis/build_canonical_results.py

Known limitations

  • Large intermediate files (segment table, per-segment relocation results, raw downloads) are regenerated by steps 1–3 and are not included.
  • OpenStreetMap is a live database. Without cache/, a re-download reflects the current map. Overpass POI queries may be refused or rate-limited, and a re-acquisition can differ from the archived snapshot. Such a run is a re-acquisition, not a byte-exact reproduction of the original inputs.
  • The quick check reproduces the reported numbers from the archived result tables. It does not re-run the hours-long optimization.
  • data/processed/ceus_rerun.log: absolute paths in warning lines were replaced with ./. No values were changed.
